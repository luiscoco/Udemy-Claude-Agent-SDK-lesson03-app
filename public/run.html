01

Set up the project and install dependencies

Use Node.js 24+ for this application, npm, Python 3.10+ for host checks, and an Anthropic API key. Git Bash may be required by the SDK on Windows. Keep optional npm dependencies enabled for the bundled runtime.

node --version
python --version

Clone the completed application:

git clone https://github.com/luiscoco/Udemy-Claude-Agent-SDK-lesson03-app.git
cd .\Udemy-Claude-Agent-SDK-lesson03-app
npm ci

In the original presentations workspace, use cd .\agent-sdk\lesson03-bug-fixing and npm ci. The presentation’s from-scratch TypeScript setup is:

mkdir my-agent
cd my-agent
npm init -y
npm pkg set type=module
npm install @anthropic-ai/claude-agent-sdk
npm install --save-dev tsx
02

Set your API key in the same shell

Replace the safe placeholder locally, then run the sample from that PowerShell terminal:

$env:ANTHROPIC_API_KEY = "your_api_key"
npm run sample

On macOS/Linux, use export ANTHROPIC_API_KEY="your_api_key" before npm run sample. The sample reads the process environment, not an automatic .env file. A new terminal needs its own assignment.

Optional explicit file loading:

if (!(Test-Path .env)) { Copy-Item .env.example .env }
notepad .env
npm run sample:env
ANTHROPIC_API_KEY=your_api_key
CLAUDE_MODEL=claude-sonnet-4-6
PORT=3103
PYTHON_BIN=python

A key already set in the shell takes precedence. Restart the web host after editing configuration. If Python is not called python, set PYTHON_BIN to its executable. On Windows, if needed, set CLAUDE_CODE_GIT_BASH_PATH=C:/Program Files/Git/bin/bash.exe.

03

Create and understand the buggy file

def calculate_average(numbers):
    total = 0
    for num in numbers:
        total += num
    return total / len(numbers)


def get_user_name(user):
    return user["name"].upper()

The fixture remains in fixtures/utils.py. Each run restores a disposable copy in .runtime/bugfix-workspace/utils.py. Initially, two normal checks pass and two edge cases fail with ZeroDivisionError and TypeError. The repaired file remains available locally after the run, until the next reset.

04

Write the agent options and run it

const conversation = query({
  prompt: "Review utils.py for bugs that would cause crashes. Fix any issues you find.",
  options: {
    cwd: WORKSPACE,
    tools: ["Read", "Edit", "Glob"],
    allowedTools: ["Read", "Edit", "Glob"],
    permissionMode: "acceptEdits",
  },
});

This short illustration shows the core options; the complete source adds the explicit contract, reset, path guard, limits and independent checks.

npm run sample:env
# Web alternative:
npm start
# Open http://127.0.0.1:3103

Keep the web terminal open. Starting it makes no model call. Each submitted repair uses the API and may incur charges. Stop it with Ctrl+C.

05

Inspect the evidence

  1. Confirm the default repair prompt and 2/4 baseline checks.
  2. Click Fix utils.py once.
  3. Observe Read and Edit requests; Glob may be used too.
  4. Wait for the final SDK outcome and the host verification event.
  5. Compare before/after code and confirm 4/4 checks plus a changed file.

A successful SDK result with failing host checks is not a verified fix. The host test runner is outside the agent workspace and is never supplied as an editable target.

06

Customise and practise

Try docstrings or type hints while preserving the four behaviour checks. A read-only experiment removes Edit from tools and changes the prompt to a bug report; its file should remain unchanged, so the UI should not claim a verified repair. The slides also discuss Bash and WebSearch as future extensions. They are not enabled in this app; adding them requires updating both the tool set and the local guard deliberately.

npm test
npm run build:client
python scripts/build-pages.py

If Python checks are unavailable, fix Python/PYTHON_BIN before spending an API call. If a runtime or Git Bash error occurs, keep optional dependencies installed and verify the Git Bash path. If this app already owns port 3103, a second start prints its URL; otherwise stop the other service or choose another PORT.
